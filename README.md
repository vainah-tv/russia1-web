# Эфир для iPhone — публикация в GitHub Pages

Веб-приложение для Safari: Россия 1HD, Вайнах ТВ и Радио Грозный. Адреса и обложка перенесены из предоставленного Android-проекта. Это отдельная веб-версия; Xcode, IPA и сертификаты Apple не нужны.

## Публикация

1. Создайте новый репозиторий, например `russia1-web`. На бесплатном GitHub выберите Public. Не заменяйте этим архивом Android-проект: используйте отдельный репозиторий.
2. Загрузите содержимое архива в корень ветки `main`: папки `web`, `scripts`, `.github`, README.md. Не загружайте сам ZIP и не создавайте дополнительную внешнюю папку.
3. Если `.github` пропускается при загрузке: Add file → Create new file → имя `.github/workflows/ios-web.yml`. Скопируйте весь текст из файла `ios-web.yml.txt`, затем Commit changes. В файле нет строк diff и знаков `+`.
4. Settings → Pages → Build and deployment → Source → **GitHub Actions**. В Settings → Actions → General разрешите Actions и используемые actions. Настроенные workflow permissions самостоятельно выдаются workflow; секреты не нужны.
5. Actions → **iPhone Web Pages** → Run workflow → main → Run workflow. После включения Pages повторите запуск, если первый запуск завершился ошибкой.
6. Дождитесь зелёной галочки. Ссылка находится в последнем запуске, в разделе deployment, и в Settings → Pages. Обычно она имеет вид `https://ВАШ-ЛОГИН.github.io/russia1-web/`.
7. Откройте ссылку в Safari на iPhone. Запускается последний выбранный канал без звука; при первом открытии — Россия 1HD. Нажмите «Включить звук» или выберите канал. Чтобы добавить значок: Поделиться → На экран «Домой».

Если ветка называется иначе, измените `branches: [main]` в workflow. Если GitHub просит разрешить развёртывание для environment `github-pages`, проверьте Settings → Environments → github-pages: ветка main должна быть разрешена.

## Особенности веб-версии

- Safari воспроизводит HLS средствами браузера. Chrome/Firefox на компьютере без встроенной поддержки HLS покажут просьбу открыть Safari. Дополнительных CDN-зависимостей нет.
- Выбранный канал сохраняется в браузере и восстанавливается при открытии. Если сохранение в браузере недоступно, используется Россия 1HD. При открытии эфир запускается без звука; звук включается кнопкой «Включить звук». Если Safari блокирует автозапуск, остаётся ручной запуск кнопкой «Запустить эфир». Пауза, отключение звука и полный экран доступны. На iPhone громкость регулируется физическими кнопками телефона.
- ТВ и радио используют один HLS-плеер. Оригинальная обложка `web/assets/radio_gr.png` отображается поверх всей области видео при выборе радио, даже если поток ещё загружается или недоступен. Кнопка полного экрана отключена для радио.
- EPG России 1 открывается отдельной страницей источника; загрузка HTML программы внутрь приложения не реализована, чтобы не зависеть от разрешений CORS и формата сторонней страницы.
- Service Worker сохраняет оболочку приложения. Эфир и программа требуют интернет. Работа в фоне или при заблокированном экране зависит от Safari и iOS; не гарантируется.
- Потоки сторонние. Их адреса могут измениться, а сервер может ограничивать регион или воспроизведение с другого сайта. GitHub Pages только публикует интерфейс и не ретранслирует видео. При отказе сервера публикация сайта не исправит поток. Адреса находятся в `web/app.js`.
- Первый канал запускается через ту же процедуру подготовки плеера, что и переключение каналов. Сохранено раннее подключение к серверу России 1HD. Если за 12 секунд ещё нет даже метаданных потока, выполняется одна повторная загрузка того же канала; поток, который уже загружается, не сбрасывается. Кнопка «Запустить эфир» также перезапускает зависшую загрузку без переключения канала. Скорость реального запуска зависит от сети и буферизации Safari.
- Ссылки и интерфейс используют относительные пути: приложение работает в подпапке репозитория.

## Проверка локально

Требуется Node.js 24; пакеты npm не нужны:

```sh
node --check web/app.js
node --check web/sw.js
node scripts/build.mjs
python3 -m http.server 8080 --directory dist
```

Откройте http://localhost:8080. На телефоне для установки оболочки используйте HTTPS-ссылку GitHub Pages.

## Проверка перед выдачей

Проверены синтаксис JavaScript, сборка, структура и относительные пути. В WebKit проверены обложка радио на мобильном и настольном экранах, сохранение и восстановление ТВ/радио, кнопки звука и паузы, обработка отказа автозапуска и некорректного сохранённого значения. В тестах поведения воспроизведение имитировалось. Linux-версия WebKit в этой среде не поддерживает HLS; это не проверка реального эфира в Safari на iPhone. Реальное воспроизведение в Safari на iPhone и запуск workflow в вашем репозитории необходимо проверить после публикации. Плейлист России 1HD при последней проверке возвращал HTTP 200; это не подтверждает воспроизведение всех фрагментов на iPhone.

Документация: https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages

## Обновление до версии 5

Замените всю папку `web` из архива, включая `web/assets/radio_gr.png`, и файл `scripts/build.mjs`. Не ограничивайтесь одним app.js: новые HTML, CSS и путь картинки должны обновиться вместе. После успешного workflow закройте старую вкладку и откройте ссылку снова. Стили, код и обложка используют версию в URL, чтобы браузер не подставил старые файлы из кэша.
